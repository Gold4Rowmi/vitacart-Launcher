Files Commands

Give each game the art its real media carries: a disc scan for PSP and PS1, a cover for a Vita card. Drop an image on a game or choose a file. Everything is written to RetroFlow Float's own folder on the Vita, never to RetroFlow.

Position the disc

Drag the circle onto the disc and size it to the edge. The label is cut from inside the circle.
